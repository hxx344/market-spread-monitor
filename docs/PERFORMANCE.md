# 前端性能验证

2026-09-16，以 `b9b61a4` 为优化前基线。使用同一份真实归档数据：原油 5,000 根 15 分钟记录、海力士小时历史；本地生产构建、独立 SQLite、关闭外部采集与消息发送。Chromium 每轮清空浏览器缓存，桌面宽 1,440，手机宽 390，并对手机场景设置 4 倍 CPU 降速。各场景运行 3 次，以下为中位数，属于本地受控测量，不是线上用户指标。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 桌面打开原油全部明细 | 808 ms | 28 ms |
| 模拟手机打开原油全部明细 | 3,297 ms | 47 ms |
| 明细首屏生成的记录数 | 5,000 | 200 |
| 模拟手机切换全部历史 | 56 ms | 35 ms |
| 模拟手机批量处理 200 次指针移动 | 638 ms | 11 ms |
| 首屏重复请求原油、海力士价格历史 | 2 次 / 450,753 字节 | 0 次 / 0 字节 |
| 首页 HTML 解码后大小 | 584,155 字节 | 569,347 字节 |

明细优化后每页 200 条，翻页仍可访问所有原始记录；并非把 5,000 条全部绘制耗时降到了 47 ms。指针测量是同一任务内连续派发 200 个事件，再等待两次绘制帧：新版在一帧内只处理最后一次位置，因此这一数字反映事件合并效果，不应当作真实设备的 INP。

## 实现

- 首屏直接使用本次服务器读取的历史；浏览器不立即重复获取。若没有首屏历史或它已在传输、恢复过程中停留超过 60 秒，则立即读取。报价仍立即刷新，历史每 60 秒继续检查，手动刷新不受影响。
- 去掉首屏已经不使用的原油日线数据，日线 API 与数据库保持可用。
- 原油明细分页；区间、统计、曲线和累计资金费继续使用完整数据。
- 指针处理按绘制帧合并，二分查找最近的实际观测；保留缺口、较早点优先的等距规则和键盘逐根查看。离开图表会取消待处理提示。
- 历史价格不变时保留曲线与表格；资金费仅状态变化时更新状态文字。两腿的任何价格修正、时间变化、新增记录或缺口变化都会重新处理。
- 原油迷你图缓存由各自面板持有，报价刷新复用历史点；更新历史来源时间和过期状态时仍保留准确标记。格式化时间时复用格式器。隐藏面板不绘制原油价格图，重新打开时按新尺寸恢复。

## 验证范围

单元测试检查定时刷新与卸载取消、二分查找和缺口、全部分页无遗漏无重复、价格修正识别、历史与当前报价分离。浏览器检查原油区间、明细翻页、键盘和指针、相同历史刷新、历史修正、缺口、断网首屏保留、市场切换及 320/390/768/1,440 宽度。
