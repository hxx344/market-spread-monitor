# 手动配对

在合约价差页面展开“手动配对”，搜索并选择两个不同交易所的合约，填写各侧价格换算倍数后添加。支持编辑、删除，最多保存 20 组；配置仅保存在当前浏览器，刷新后保留，切换设备不共享。

换算价格 = 行情页面报价 × 该侧倍数。两侧必须换算至同一标的单位。例如两份合约报价分别为 100 和 10，且代表相同估值，则倍数可设为 1 和 10。这里使用的是页面已经归一化的报价，不能再次套用交易所的张数乘数。

手动配对独立展示两个买卖方向，不受自动排名的币种、平台组合和阈值筛选影响；使用当前“买卖盘口 / 标记价格”口径和手续费预算。跨计价币自动使用新鲜现货买卖汇率换算到 USDT，汇率缺失时不计算价差。净价差扣除双边开平仓 taker 费用和滑点预算，换汇手续费另计。标记价格模式不计算净价差。

用户选择只覆盖这两个合约的身份隔离，不修改行情目录或自动配对规则。手动结果不送入自动提醒、历史质量评分或持仓登记，因为这些服务尚未接收手动单位换算配置。独立合约原有的手续费未知状态继续保留，不继承普通加密合约费率。

报价过期、缺失、时间错位超过 5 秒、平台不在线、换算溢出或无有效汇率时，不显示有效价差。合约暂时消失时保留配置并提示原因。资金费率缺失显示空值。用户仍需自行核对标的、单位和结算条款；页面明确标注“手动配对 · 未核实规格”。

验证：`node --experimental-strip-types --test tests/perpetual-manual-pairs.test.mjs tests/perpetual-spreads.test.mjs tests/perpetual-fees.test.mjs`。
